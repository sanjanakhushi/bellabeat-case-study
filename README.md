# Bellabeat Case Study

## Google Data Analytics Capstone Project

This project is part of the **Google Data Analytics Professional Certificate**. The objective was to analyze smart device usage data and provide marketing recommendations for **Bellabeat**, a wellness technology company that develops health-focused smart products for women.

---

## Business Task

Analyze Fitbit fitness tracker data to identify trends in smart device usage and provide data-driven recommendations to help Bellabeat improve its marketing strategy.

---

## Tools Used

- SQL
- Python (Pandas, NumPy)
- Tableau
- Microsoft Excel

---

## Dataset

- Fitbit Fitness Tracker Data
- Public dataset provided through Kaggle
- Data includes daily activity, sleep, calories, steps, and hourly activity.

---

## Project Workflow

### 1. Data Cleaning
- Removed duplicate records
- Checked missing values
- Standardized date formats
- Filtered invalid records

### 2. Data Analysis
- Daily activity analysis
- Sleep pattern analysis
- Calories burned analysis
- Hourly activity trends
- Weekday vs Weekend comparison

### 3. Data Visualization
Created interactive dashboards in Tableau to visualize:
- Daily Steps
- Calories Burned
- Sleep Duration
- Hourly Activity
- Activity by Day of Week

---

## Key Insights

- Users are generally more active during weekdays than weekends.
- Higher step counts are associated with increased calorie burn.
- Many users do not consistently achieve recommended daily activity levels.
- Activity peaks during the evening hours.
- Sleep duration varies significantly among users.

---

## Recommendations

- Encourage users to achieve daily step goals through personalized reminders.
- Promote consistent sleep habits using sleep tracking insights.
- Create targeted campaigns based on user activity patterns.
- Introduce personalized wellness challenges to improve engagement.
